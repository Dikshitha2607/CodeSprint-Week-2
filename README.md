# CodeSprint Week 2
## Problem Statement
Industrial machines generate large amounts of multivariate sensor data, making it difficult to manually identify recurring patterns in anomalous machine behaviour.
This project aims to use **unsupervised machine learning to discover and group recurring patterns among anomalous machine behaviour**, without requiring predefined pattern labels.

## Approach
The project is currently in the **dataset feasibility testing stage**.

### MVTec AD
MVTec AD was used as the initial feasibility test using visual anomaly data.

Two experiments were performed:
- Whole-image visual embeddings
- Defect-region visual embeddings

The results were **inconclusive** for the proposed problem statement.

### TiNA
The next stage is to evaluate the **TiNA industrial time-series dataset** to determine whether recurring patterns can be discovered more effectively from multivariate machine behaviour over time.

## Current Status
**MVTec AD:** Inconclusive  
**TiNA:** Under evaluation
